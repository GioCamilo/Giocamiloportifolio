About the project

Developed in partnership with Mangels, this project focuses on creating a supervisory platform for industrial machine monitoring. The system is designed to display operational information in a clear interface, support real-time visualization and allow future expansion to new departments and machines.

This was my first large-scale project in an industrial environment, combining software development, data collection, interface design, database organization and deployment concerns. The project continues to evolve as new requirements, machines and departments are added.

Languages and tools

Technical challenges

  • Organizing real-time data collection from industrial machines.
  • Designing a clear interface for factory operators and technical teams.
  • Structuring the system to receive new machines and departments.
  • Preparing historical data for analysis, reports and operational decisions.
  • Maintaining the application in a Linux/server-oriented environment.

Infrastructure focus

Beyond the application itself, the project also involves concerns normally found in production environments: server configuration, internal network access, database persistence, logs, process stability and future deployment improvements.

  • Linux environment for hosting and maintenance.
  • Nginx/reverse proxy concepts for web access.
  • Database persistence with PostgreSQL / SQL.
  • Future-ready structure for Docker and automated deployment.

What I learned

  • Building scalable backend structures with Python and Flask.
  • Creating dashboards focused on usability and operational clarity.
  • Working with SQL databases for industrial historical data.
  • Understanding the importance of Linux, deployment and system reliability.
