Sobre o projeto

O que foi construído

O Escopo Project foi desenvolvido para substituir um processo dependente de planilhas Excel, fórmulas difíceis de manter e informações espalhadas entre arquivos e equipes.

A solução centraliza a criação de escopos e projetos em uma aplicação web interna, reduz retrabalho, melhora a rastreabilidade e facilita a consulta histórica dos dados mais importantes para Engenharia Industrial e Manutenção.

Python Flask PostgreSQL JavaScript HTML5 CSS3 Bootstrap Docker Linux Nginx
Qualificações do projeto

Por que essa solução se destaca

Centralização

Um único ponto de entrada para criar, consultar e acompanhar projetos e escopos.

Padronização

Fluxo consistente, com campos organizados e menos dependência de preenchimentos manuais.

Escalabilidade

Base preparada para crescer com novas regras, novos campos e novas telas sem perder organização.

Rastreabilidade

Registro histórico das informações para consulta, auditoria interna e análise posterior.

Ganhos do projeto

Impacto operacional gerado

  • Redução da dependência de planilhas e fórmulas complexas.
  • Maior velocidade na criação de projetos e escopos.
  • Menos retrabalho com reutilização de informações recorrentes.
  • Melhoria na organização e na leitura dos dados por diferentes áreas.
  • Controle mais confiável de numeração, histórico e documentos gerados.
Resultado prático

O processo ficou mais simples para o usuário interno e mais sustentável para manutenção técnica, com melhor organização da informação e menos pontos de falha.

A solução facilita evolução futura sem quebrar o fluxo principal do negócio.

Arquitetura utilizada

Estrutura técnica do sistema

A arquitetura foi pensada para transformar um fluxo manual em uma aplicação web centralizada, com persistência de dados, documentação organizada e suporte ao uso interno.

Usuários internos

Engenharia e manutenção acessam o sistema para criar e consultar informações.

Flask Backend

Regras de negócio, rotas e processamento central da aplicação.

Banco de dados

Armazenamento estruturado de projetos, escopos, histórico e dados recorrentes.

Servidor Linux

Publicação e manutenção em ambiente interno com suporte ao ciclo da aplicação.

Desafios e aprendizados

Technical Challenges
  • Substituir um processo baseado em Excel por uma aplicação web centralizada.
  • Organizar dados de projetos e escopos de forma mais estruturada.
  • Criar uma experiência simples para usuários internos não técnicos.
  • Preparar o sistema para futuras melhorias, novos campos e novas regras de negócio.
  • Manter consistência entre geração de números, histórico e documentos.
Learning Outcomes
  • Desenvolvimento backend com Python e Flask.
  • Modelagem e persistência de dados em banco relacional.
  • Criação de interfaces web focadas em produtividade operacional.
  • Uso de Linux, Docker e Git no ciclo de desenvolvimento.
  • Transformação de um processo manual em um sistema mais escalável.
